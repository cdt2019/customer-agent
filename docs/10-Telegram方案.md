# Telegram 渠道 · 方案

| 项 | 内容 |
|---|---|
| 版本 | v1.0（2026-11-25 已确认） |
| 范围 | 买家在 Telegram 上私聊店铺的机器人，走和聊天窗同一套对话：AI 回答、转人工、客服在后台接手、发图片 |
| 不做 | 群聊和频道；机器人主动给买家发营销消息；Telegram 上付款下单 |
| 前提 | 网络已试过（docs/05 §36）：测试服务器直连稳定，开发机要走代理。店铺要用自己的 Telegram 账号在 @BotFather 建机器人，拿到店铺自己的机器人令牌 |

## 1. 和网页聊天窗有什么不同

| | 网页聊天窗 | Telegram |
|---|---|---|
| 谁在中间 | 接入方的网站转发，带访客令牌 | 客服服务直接和 Telegram 说话，不经过接入方 |
| 买家是谁 | 接入方签的访客令牌，能查自己的订单 | 只有 Telegram 账号，**接入方不认识他，查不了订单**（见§6 第 1 条） |
| 回答怎么到 | 流式，一个字一个字出 | 整段生成完发一条，期间显示「正在输入」（见§6 第 5 条） |
| 客服的回复怎么到 | 聊天窗每 5 秒来拉 | 客服一发，服务马上推给 Telegram |

## 2. 买家怎么用

- 在 Telegram 里搜到机器人，点「开始」：回一句欢迎语，下面是后台「接入方」页里的常见问题按钮（按买家 Telegram 的语言选中文或英文）。
- 直接发文字问；发图片也行（走 docs/09 那一套，清洗后存下来，AI 说明看不到）。
- 命令：`/new` 开新对话，`/human` 转人工。
- 转人工：因为查不了订单，按「没订单」的路子走：请买家留邮箱，通知店主（和网页上游客转人工一样）。客服也可以直接在后台接手回复。
- 回答里的出处在末尾列标题（见§6 第 6 条）。
- 一个 Telegram 账号对应一个进行中的对话；超过 24 小时没说话，下一句自动开新对话。

## 3. 服务怎么跑

- **收消息**：服务启动时起一个后台任务，用「长轮询」不停地问 Telegram 有没有新消息（不需要公网地址，服务器能直连 Telegram 即可）。服务只有一个进程，不会重复收。
- **回答**：每条消息交给和网页一样的对话流程（`chat/agent.py`），渠道记为 `telegram`，访客编号是 `tg:<Telegram 用户编号>`，限额照样按访客算。生成期间每 5 秒发一次「正在输入」。
- **客服接手**：后台回复框发出的话，如果会话是 Telegram 的，马上推给买家；交还给 AI、30 分钟自动交还时的说明也推过去。
- **总开关关了 / 到了每日上限**：回一句暂停说明和店铺联系方式，和聊天窗一样。
- **出错**：Telegram 连不上时等几秒重试，不影响网页聊天窗和后台；同一条消息不会回两次（按 Telegram 的消息编号记着处理到哪了）。

## 4. 代码和配置

| 改动 | 说明 |
|---|---|
| `channels/telegram.py` | 新模块：长轮询收消息、发消息、发「正在输入」、下载图片。只管和 Telegram 说话，不懂对话 |
| `channels/__init__.py` 里的推送 | 后台回复、交还时按会话的渠道推出去：Telegram 的推给 Telegram，网页的什么都不做（聊天窗自己拉）。这是把「推给哪个渠道」放在一个地方，对话和人工接管的代码不认识 Telegram |
| `api/__init__.py` | 配了令牌才在启动时起长轮询任务 |
| 环境变量 | `TELEGRAM_BOT_TOKEN`（令牌，只放 `.env`）；`TELEGRAM_INDEX_ID`（用哪个索引回答，见§6 第 2 条）；`TELEGRAM_PROXY`（只在需要代理的机器上配） |
| 表 | 不改。会话的 `channel` 和 `visitor_id` 够用；「处理到哪条消息」存在服务设置那一行里，重启不丢 |
| 后台 | 会话记录里渠道显示「Telegram」；「接入方」页的运行信息加一行「Telegram 机器人：@名字 / 没配置」 |

## 5. 怎么验收

- 单元测试：用假的 Telegram 接口（httpx 的假传输），测收到文字 → 回答发出去、`/new` 开新对话、24 小时后开新对话、同一条不回两次、客服回复推出去、总开关关了回暂停说明、图片走清洗。
- 真机器人：开发机走代理、测试服务器直连各试一遍：问答、发图、转人工留邮箱、后台接手回复、交还。
- 端到端脚本不加 Telegram（要真账号收发，没法自动化），手动验收的结果记进 docs/05。

粗估：2–3 天。

## 6. 定下的做法

1. 第一版不查订单：问到订单时请买家到网店「查订单」页，转人工按留邮箱走。账号绑定等接入真实店铺时再谈。
2. 用环境变量 `TELEGRAM_INDEX_ID` 指定索引。
3. 只理私聊。
4. 图片一起支持。
5. 整段生成完发一条，期间显示「正在输入」。
6. 出处末尾只列标题。
