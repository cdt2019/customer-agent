## 1. 设计方向

**蓝色软卡片**：淡蓝紫渐变底，白色大圆角卡片，靠柔和阴影分层，宝蓝色做强调。结构借鉴 Google AI Studio 的后台（分组左侧菜单、底部工具按钮），质感参考蓝色系的移动端设计。

### 1.1 评审时定下的取舍

这些是改过几轮才定的，实现时不要改回去：

| 不要 | 要 | 原因 |
|---|---|---|
| 素净的灰白工具风、紫色主题 | 宝蓝软卡片 | 太素；紫色的配色和质感不合适 |
| 输入框和回答分在页面两头 | 聊天式：上面输出、下面输入 | 输入和输出隔太远 |
| 对话占大半屏 | 对话固定 410 像素，可收起 | 检索结果才是测试台的主角 |
| 四路检索同时并排 | 标签页切换，一次看一路 | 四列内容太多、重复，不方便看 |
| 只有图标的窄导航 | 带产品名、当前项目、分组的左侧菜单，可收起成图标栏 | 要看得到项目名称 |
| 一张卡片占大半指标栏 | 指标等宽排开，主卡只略宽 | 「交给模型」太宽 |

## 2. 设计令牌

颜色只定义在令牌文件里，页面只用令牌类。

### 2.1 颜色

| 令牌 | 值 | 用途 |
|---|---|---|
| `ink` | `#14172b` | 主文字 |
| `ink-2` | `#545a78` | 次要文字 |
| `ink-3` | `#8e93ad` | 说明、未选中 |
| `blue` | `#2d5bff` | 强调色、选中 |
| `blue-deep` | `#1b3fe0` | 渐变终点 |
| `blue-soft` | `#e8edff` | 选中底色、悬停底色 |
| `chip` | `#eceefa` | 小标签底色 |
| `card` | `#ffffff` | 卡片 |
| `tile` | `#f6f7fd` | 卡片里的列表项 |
| `up` | `#12996a` | 变好、上升 |
| `down` | `#e0475c` | 变差、下降 |
| `warn-soft` / 文字 `#9a6200` | `#fff3da` | 「应找到」、提醒 |

页面背景：`linear-gradient(180deg, #c6cbf0 0, #dfe2f7 150px, #f3f4fc 340px, #fafbff 100%)`，固定不随内容滚动。

**渐变只用在**：品牌标、主按钮、当前最重要的一张指标卡、用户气泡、聊天窗头部。其他地方用纯色。

### 2.2 圆角

| 元素 | 圆角 |
|---|---|
| 大面板 | 24px |
| 指标卡 | 18px |
| 列表项 | 16–18px |
| 按钮、输入框 | 12px |
| 小标签 | 8–9px |

### 2.3 阴影

| 令牌 | 值 | 用途 |
|---|---|---|
| `shadow` | `0 1px 2px rgba(38,48,110,.04), 0 12px 32px -14px rgba(38,48,110,.18)` | 卡片。卡片不加边框 |
| `shadow-blue` | `0 14px 26px -12px rgba(36,76,245,.6)` | 蓝色主按钮、主卡 |

### 2.4 文字

字体：`Segoe UI`、`Microsoft YaHei UI`、`PingFang SC`。数字用 `Segoe UI Variable Display`，加粗。

| 用途 | 字号 | 字重 |
|---|---|---|
| 页面标题 | 22px | 700 |
| 面板标题 | 15–17px | 700 |
| 列表标题 | 15px | 600 |
| 正文 | 14px | 400 |
| 说明 | 12–13px | 400 |
| 小标签 | 11.5–12px | 400 |
| 指标数字 | 18–23px | 700 |

### 2.5 图标

lucide，线条 1.8。菜单里 17px，按钮里 15–20px。

## 3. 通用布局

### 3.1 后台外框

```
┌────────┬──────────────────────────────┐
│ 左侧菜单 │ 页面标题         选择器  主按钮 │
│ 232px  ├──────────────────────────────┤
│        │ 指标栏（72px 高）              │
│ 可收起  ├──────────────────────────────┤
│ 成 58px │ 工作区，自己内部滚动            │
└────────┴──────────────────────────────┘
```

- 整页不滚动，只有工作区内部的列表滚动。
- 窗口窄于 1240 像素时，左侧菜单默认收起。

### 3.2 左侧菜单

从上到下：产品名和收起按钮、当前接入方卡片、分组菜单、账号卡片。原来设计的四个工具按钮（通知、设置、搜索、接口密钥）不做（2026-11-25 定）：转人工的待处理条数直接显示在「转人工」菜单后面，有没通知到店铺的标红；只读的运行信息放在「接入方」页；服务密钥不在页面上显示或更换。

| 分组 | 菜单 | 第一版 |
|---|---|---|
| 知识库 | 数据集、导入和解析、切块实验室、任务 | 做 |
| 检索与评测 | 检索测试台、评测 | 做 |
| 客服运营 | 会话记录、转人工 | 第二步，先显示标记 |
| 用量与接入 | 用量和花费 | 第二步，先显示标记 |
| 用量与接入 | 接入方 | 做简单版 |

收起后只留图标，鼠标移上去显示名字。

### 3.3 通用组件

| 组件 | 规矩 |
|---|---|
| 指标卡 | 上面小字说明，下面大号数字加单位；放不下时换行排布，内容不溢出 |
| 标签页 | 选中的文字变蓝，下面一条 2.5px 蓝线 |
| 列表项 | `tile` 底色，悬停变 `blue-soft`；点开看全文 |
| 名次变化 | `▲ 2` 绿色，`▼ 1` 红色，不变写「持平」 |
| 选择器 | 半透明白底，「说明 + 加粗的当前值 + 下箭头」 |

## 4. 页面

### 4.1 检索测试台

| 区域 | 内容 |
|---|---|
| 对话（410px，可收起到 66px） | 上面是对话，下面是输入框；输入框里有改写、语义、关键词、融合、重排五个开关 |
| 检索过程标题 | 当前问题、改写结果、知识库和索引版本选择 |
| 指标栏 | 最高相关度、交给模型、应找到的名次、检索耗时、回答耗时、本次花费；够宽时加读入和写出 |
| 结果列表 | 标签页：最终排名、语义检索、关键词、融合 |

- 右边始终显示**选中那条回答**的检索过程，点别的回答就切换。
- 每条结果显示名次、标题、位置、分数、一行正文，以及它在四步里各排第几。
- 「最终排名」标出比融合时升降了几名，第 5 名下面有「以上 5 块交给模型」分界线。
- 点回答里的出处编号，定位到对应的块并高亮。
- 窄于 980 像素时，检索过程变成从右边滑出的抽屉。

### 4.2 数据集

- 顶部：切换知识库、索引版本、向量地图（打开 Qdrant 面板）、全部重建、导入文件、现在同步。
- 指标：文档、块、平均长度、待更新、向量模型、上次同步。
- 左边文档列表（318px）：搜索、按类型筛选，改过未同步的标「待更新」。
- 右边**原文和块左右对照**，鼠标移到一边，另一边对应部分高亮。

### 4.2.1 导入和解析

- 左边（318px）：拖拽上传区和文件列表，状态分排队、解析中、待确认、已确认、失败。
- 右边：顶部是文件名、解析器切换、重新解析；下面一排检查项，可疑的用黄色。
- 主体是**原文件和 Markdown 左右对照**，Markdown 可以直接改。
- 底部：去掉页眉页脚、跳过、「确认，开始切块」。确认后自动跳到下一份待确认的文件。

### 4.2.2 切块实验室

- 三栏：切块设置（276px）、切块预览、块列表（330px）。
- 指标栏显示块数、平均、最短、最长、过短、过长，并和在用设置比较。
- 改参数立刻重新计算。块用两种底色交替，重叠部分标黄，过短和过长的块在列表里标红。
- 鼠标移到预览或列表，两边对应的块一起高亮。

### 4.2.3 任务

- 标签页：全部、进行中、失败、完成。
- 每个任务一张卡片，五段进度条：解析、清洗、切块、向量化、入库。完成绿色、进行中蓝色、失败红色。
- 失败的直接显示原因和「重试」，进行中和排队的可以取消。

### 4.3 评测

- 左边是评测记录，点一条作为对比对象，并标出「基准」「对比」。
- 右边五个分数带升降：前 5 命中率、MRR、忠于资料、行为正确、刁钻题。刁钻题用蓝色卡片，因为上线要求 100%。
- 题目按「变差、变好、全部」分，默认看变差。点开看应找到的文档、说明，以及去测试台的入口。

### 4.4 聊天窗

一套组件，悬浮和整页两种外壳。

| 项 | 规矩 |
|---|---|
| 悬浮版 | 右下角按钮，面板宽 400px，高最多 640px |
| 手机 | 窄于 520 像素时占满全屏 |
| 整页版 | 内容最宽 820px |
| 头部 | 名称加「AI 回答，可随时转人工」；「转人工」在任何状态下都看得见 |
| 首屏 | 一句说明、3–5 个常见问题按钮 |
| 回答 | 查询时显示「正在查资料」「正在查订单」；下面列出处、「有用」「没用」 |
| 转人工 | 绿色结果卡，写明工单号或回复邮箱、预计时间 |
| 输入 | Enter 发送，Shift + Enter 换行，最多 500 字 |
| 底部 | 「聊天记录保存 90 天 · 请勿发送密码和卡密」 |

- 买家发的内容里像密码、验证码的部分，**显示时也打码**。
- 嵌入别的网站时，样式不能和宿主页面互相影响。建议用 Shadow DOM，实现时验证。

### 4.5 模拟店铺

用来测试聊天窗。（2026-11-24 定）照真实网店前台的首页做（配色、页头、首屏横幅、服务承诺、热卖卡片），页面看起来像一家真实网店，不写「模拟」「测试」之类的字样（店名叫「示例商店」）。有首页、商品、我的订单、帮助、在线客服；右上角「切换身份」在游客、会员甲、会员乙之间切。

## 5. 文案

- 全部中文，聊天窗另有英文。
- 对买家讲事实和可以怎么做，不下命令：写「可以在订单页查看」，不写「请你必须去订单页」。
- 不装成人，明确是 AI。
- 不替店铺承诺：退款、补发、质保认定都写「需要客服确认」。
- 后台给自己看的可以直说。

## 6. 交互和前端规则

前端规矩：

1. 基础组件只来自 shadcn 的 Base UI 版（`base-nova`），不手搓弹窗、下拉、标签页、开关。
2. 页面里不写原生的 `<button> <input> <select> <textarea> <table> <dialog>`。效果图是纯 HTML，用了这些标签，实现时要换成组件。
3. 不写死颜色，只用令牌类。
4. 界面文字放在文字文件里。
5. 点下去立刻有反馈；0.1 秒出进度条，0.3 秒出骨架。
6. 一排按钮在各种状态下宽度不变，滚动条出现时版面不晃。
7. 不用浏览器原生的下拉框和日期选择。

无障碍：图标按钮都有名称，键盘能操作并看得见焦点，尊重「减少动态效果」的系统设置。

## 7. 响应式

| 宽度 | 后台 | 聊天窗 |
|---|---|---|
| ≥ 1240 | 完整布局 | 悬浮 |
| 980–1240 | 菜单默认收起，指标可换行 | 悬浮 |
| 760–980 | 检索过程变抽屉 | 悬浮 |
| < 760 | 隐藏菜单，后台不作为主要场景 | 520 以下全屏 |

## 8. 效果图的已知差距

- 内容、分数都是示意；聊天窗的回答按关键词匹配，没有接模型。
- 知识库、评测页在窄屏下没有专门核对，实现时要看。
- 「Customer Agent」是暂用名，Logo 也是占位。
