# 人工接管 · 方案

| 项 | 内容 |
|---|---|
| 版本 | v1.0（2026-11-25 已确认，同日在模拟店铺做完，实测见 docs/05 §33） |
| 范围 | 客服在后台直接回复买家；买家在聊天窗里看到。先在模拟店铺上做 |
| 不做 | 多个客服分工、客服之间转交、已读回执、正在输入、语音视频、发图片（另一件事） |
| 前提 | 表里 `messages.role` 早就留了 `staff`（技术方案 §4），不用改消息表 |

## 1. 现在是什么样

- 转人工以后，有订单的在店铺建工单，没订单的留邮箱、通知店主；客服在工单里或按邮箱回复，**不在对话里回**。
- 转人工以后 AI 照旧回答别的问题（端到端检查里有这一项）。
- 聊天窗只在打开时读一次历史，之后只在买家发消息时收到回答，没有「对方发来新消息」这回事。

## 2. 会话的三种状态

| 状态 | 什么时候 | AI 答不答 | 聊天窗显示 |
|---|---|---|---|
| `open` | 平常 | 答 | — |
| `handoff` | 转了人工，客服还没来 | 答（同现在） | 转人工卡片：工单号或邮箱、回复时间 |
| `staff` | 客服在后台发了第一句话 | **不答**，买家的话只存下来给客服看 | 顶上一条「客服 ×× 在和你聊」；客服的话用另一种气泡，标「客服」 |

- 客服点「交还给 AI」回到 `open`。转人工记录（`handoffs` 表）的「已处理」照旧单独标，两件事不绑在一起：交还了也可能还没处理完，处理完了也可能还想再聊。
- 客服接手期间，买家发的话不算 AI 的限额（不花模型的钱），但单条字数上限照旧。
- 客服不说话超过 30 分钟（可以改），自动交还给 AI，并在聊天窗里说一句「客服暂时离开，有问题可以继续问 AI」。免得客服忘了交还，买家一直没人理。

## 3. 买家怎么看到客服的回复

聊天窗**定时拉**，不开长连接：

- 会话在 `handoff` 或 `staff` 状态、页面在前台时，每 5 秒问一次「编号大于 N 的新消息」；页面切到后台就停，回来再拉一次。
- 拉的是现有的取历史接口，加一个参数：`GET /v1/conversations/{id}?after=<消息编号>`，只回新消息和当前状态。接入方的转发照原样带上这个参数（模拟店铺改一行）。
- 每次拉的时候记下「买家最近一次在看」（`conversations.visitor_seen_at`），后台据此显示「买家 1 分钟前还在」或「买家已经离开 2 小时」。

为什么不用推送：要多维护一条长连接，接入方的转发也要跟着支持；5 秒的延迟对客服对话够用，每次请求很轻（大多数时候回空）。以后真不够再换。

## 4. 后台怎么用

**会话记录页**（已有）右侧对话下面加：

- 回复框和「发送」。发第一句时会话变成 `staff`。
- 「交还给 AI」按钮；状态和「买家最近一次在看」显示在对话标题旁。
- 客服的话在记录里标「客服」，和 AI 的回答区分开。

**转人工页**（已有）每张卡片加「去回复」，跳到会话记录页这一条。

**提醒**：左侧「转人工」后面的条数，加上「客服接手中、买家发来新话还没回」的会话数（见§7 第 1 条）。后台每 15 秒刷新一次正在看的那段对话。

## 5. 接口和表的改动

| 改动 | 说明 |
|---|---|
| `conversations.status` 多一个值 `staff` | 不改列，只是多一种值 |
| `conversations.visitor_seen_at` | 新列，可空 |
| `conversations.staff_at` | 新列：客服最近一次说话的时间，用来算 30 分钟自动交还 |
| `GET /v1/conversations/{id}?after=N` | 接入方接口：只回编号大于 N 的消息；顺带更新 `visitor_seen_at` |
| `POST /v1/conversations/{id}/messages` 在 `staff` 状态下 | 只存买家的话，不调模型；SSE 只回 `user` 和 `done` |
| `POST /api/chats/{id}/reply` | 后台：客服发一句；会话变 `staff` |
| `POST /api/chats/{id}/release` | 后台：交还给 AI |
| 技术方案 §5.4 | 加「取新消息」的说明；接入方要做的只有把 `after` 参数带上 |

聊天窗（`widget/`）：消息多一种「客服」角色和气泡；在 `handoff`/`staff` 状态下定时拉；中英文各加几句提示。

## 6. 怎么验收

- 单元测试：三种状态的切换、`staff` 状态下不调模型、`after` 只回新消息、30 分钟自动交还。
- 模拟店铺端到端（`demo/e2e.py`）加一段：买家转人工 → 后台回复 → 买家拉到这句 → 买家再问一句 AI 不答 → 交还 → AI 又答。
- 手动在浏览器里两边各开一个窗口走一遍，看延迟和提示。

粗估：3–4 天（服务端 1.5、后台 1、聊天窗 1、测试和文档 0.5）。

## 7. 定下的做法

1. 买家又发了话：只在后台左侧「转人工」后面的条数里算上（客服接手中、买家说了话还没回的会话），不另通知店铺。
2. 买家已经离开客服才回复：不自动发邮件；回复框上方提示买家最后一次在看的时间，有工单的提示到工单里回、留了邮箱的提示按邮箱回。
3. 客服发的话不打码。
4. 客服 30 分钟不说话自动交还，先写死，不做成后台设置。
5. 聊天窗里客服统一显示「客服」。
