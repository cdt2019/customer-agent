我们只收集完成交易、售后和会员功能必需的信息，并尽量少收。

## 收集哪些信息

| 信息 | 什么时候收集 | 用来做什么 |
|---|---|---|
| 邮箱 | 下单、注册时 | 发订单链接、验证码、发货和退款通知；找回订单 |
| 订单信息（商品、金额、付款方式和时间） | 下单、付款时 | 发货、售后、对账 |
| 下单时填写的内容 | 商品要求填写时（例如接收邀请的邮箱） | 交付这个商品 |
| IP 地址、浏览器信息和大致地区 | 下单、注册、登录、申请售后时 | 防刷单、防欺诈、保护账号安全，处理纠纷 |
| 售后工单的文字和截图 | 你申请售后时 | 处理你的问题 |
| 会员的昵称、密码和登录记录 | 注册、登录时 | 登录和账号安全。密码只保存无法还原的摘要，我们也看不到 |
| 两步验证的密钥 | 你开启两步验证时 | 核对验证器上的数字 |
| 你用过的邮箱 | 会员修改邮箱时 | 防止合伙人用自己的邮箱下单拿佣金 |
| 余额和佣金流水 | 充值、付款、退款、佣金入账和提现时 | 记账、对账 |
| 合伙人的推广说明和收款账户（微信收款码、支付宝账号或 USDT 地址，以及实名） | 申请合伙人、设置收款账户时 | 审核申请、打款 |
| 推广来源 | 你点合伙人的推广链接进入本站时（记下链接、时间、IP 和进入的页面） | 把订单算给推荐你的合伙人，统计推广数据 |
| 访问统计（随机的访客编号、看过的页面和商品、设备类型、来源网站的域名） | 你浏览本站时 | 了解哪些商品和文章有人看，改进网站。不记 IP，不交给第三方 |
| 开放接口的用途说明、IP 白名单和调用记录 | 申请和使用开放接口时 | 审核、鉴权、排查问题 |
| 兑换时的账号邮箱、登录资料的指纹和 IP | 你在兑换页核对账号、开通时 | 开通，以及售后时核对 |

截图上传后会重新编码（去掉照片里的位置等信息），并加密保存。卡密、两步验证密钥和收款账户也加密保存；员工打款时查看完整的收款账户，每次查看都留有记录。

我们**不收集**你的账号密码和验证码。请不要在工单里发这些内容。

## 兑换时的登录资料

到兑换页开通 ChatGPT 等会员时，你会贴一份自己账号的登录资料（Session）：

- 它只在核对账号、开通和查询订阅这三种请求里，从你的浏览器经本站转给开通服务，用完即弃：不存进数据库，不写进日志、审计和告警。
- 我们保存的是：开通到的账号邮箱（员工能看到完整的，进度页上打码显示）、登录资料的指纹（一串无法还原的摘要，用来判断前后两次是不是同一份）、发起请求的 IP，以及开通服务的回复。
- 兑换页不设 Cookie，只在你的浏览器里记下最近 3 个兑换单号和语言选择，不记卡密和登录资料。
- 开通完成后，你可以在 ChatGPT 的设置里退出所有设备，这份登录资料随之失效。

## Cookie 和浏览器存储

| 名称 | 作用 | 保存多久 |
|---|---|---|
| 订单访问 | 记住这台设备能打开哪些订单（最近 30 笔）。没有它，你只能用邮件链接打开订单 | 90 天，有新订单时顺延；退出登录或在「查订单」里清除即删除 |
| 登录 | 会员保持登录 | 30 天，常来会自动顺延；退出登录即删除 |
| 访客编号 | 一个随机编号，用来统计访问量；你从推广链接进入时，也用它把订单算给推荐你的合伙人 | 90 天，每次访问顺延；订单只算 30 天内的推广点击 |
| 语言 | 记住你选的中文或英文 | 1 年 |
| 主题 | 记住你选的浅色或深色 | 1 年；改回「跟随系统」即删除 |
| 购物车（浏览器存储） | 记住加进购物车的商品 | 直到你清空购物车 |

我们不使用广告追踪或第三方统计类 Cookie。

## 和谁共享

只在完成交易必需的范围内，交给以下服务方：

- **支付平台**：处理付款和原路退款，拿到订单号和金额；部分通道（例如易支付）还会收到付款设备的 IP，用于它们自己的风控；
- **开通服务**：到兑换页开通时，收到你的登录资料，用来核对账号、开通和查询订阅；
- **货源方**：部分商品由上游货源方供货，我们向它下单时只提供商品和数量，不提供你的任何信息；
- **邮件服务商**：替我们发送验证码和通知邮件，会拿到你的邮箱和邮件内容（邮件里不放卡密）；
- **Cloudflare**：网站加速和防护，以及人机验证（判断是不是机器人），访问本站的请求都会经过它；
- **Telegram**：给店铺员工推送待处理的事项，内容是订单号、金额、商品名、售后工单的类型和标题等，不含卡密，邮箱会打码。

我们不会出售你的信息。法律法规要求时，我们会依法提供。

## 我们会发哪些邮件

- 和你的订单、账号直接相关的邮件：订单链接、发货、退款、工单回复、验证码、安全提醒。
- 另外只有两种：店铺给你发了优惠券的通知；你买的月卡快到期的提醒（店铺默认不发）。这两种都带退订链接，退订后不再收到，不影响上面那些邮件。

## 保存多久

- 订单、售后、余额、佣金、提现和邮件发送记录：用于售后、对账和依法留存，交易完成后至少保存 3 年。
- 售后工单的截图：工单关闭 180 天后删除。
- 登录记录、站内消息：180 天。
- 推广点击：400 天，其中 IP 和进入的页面 90 天后清除。
- 访问统计的明细：30 天，之后只留不含个人信息的每日汇总。
- 开放接口的调用记录：30 天。
- 验证码：过期 1 天后删除。

## 你的权利

- 会员可以随时在账号中心修改昵称、邮箱和密码，开启或关闭两步验证。
- 你可以通过[联系客服](/help/contact)要求查询、更正或删除与你邮箱相关的信息（法律要求保留的交易记录除外）。
